# Golf App — maquette interactive

Maquette de présentation du concept « Golf App » : cartographie des golfs de France, compétitions et contenus exclusifs membres.

- Fichier unique et autonome : `golf-app-maquette.html` (HTML, CSS et JS dans le même fichier, aucune dépendance réseau).
- Ouvrir le fichier dans un navigateur récent (Chrome, Safari, Firefox, Edge). Les écrans se parcourent en cliquant dans le téléphone.
- Région test : Landes et Côte basque. Toutes les données (golfs, compétitions, pros) sont fictives.
